# Origin Hut Data Sources

This file is the controlled register for external data sources.

No external source should be integrated into production until its API, licensing, refresh schedule, provenance and storage rules have been reviewed.

## Planned sources

### International trade

- UN Comtrade
- WTO
- World Bank WITS / UNCTAD TRAINS

### India

- DGFT
- ICEGATE
- GST / e-Invoice
- NCDEX
- AGMARKNET / data.gov.in
- APEDA

### Company identity and compliance

- GLEIF
- OpenCorporates
- Consolidated Screening List
- Other official sanctions lists

### Geography and logistics

- UN/LOCODE
- OpenStreetMap

### Weather

- Open-Meteo

### Reference data

- HS nomenclature
- countries
- currencies
- units of measure
- ports and trade locations
